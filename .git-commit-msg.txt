Security fixes, Lite mode, Forth support, repo hygiene

- Fix VULN-001: Verifier no longer allow-lists attacker-typed words,
  numbers, or names just because they appeared in the question
- Wire isAttack() into the ask pipeline (it was built and tested but
  never actually called)
- Add real Lite mode: non-WebGPU browsers get extractive-only answers
  instead of a permanently disabled chat
- Fix model temperature/max_tokens to 0.3/100 (matches DEVPOST's own
  measured claim, was running 0.7/120)
- Add a 25s generation watchdog so a hung model call can't freeze chat
- Add Forth support (waforth) alongside SNOBOL4: capability-stripped
  worker, lint, output cap, UI language picker, 5 spells verified
  against the real waforth package
- Fix a Vite worker-bundling bug (ternary inside new Worker/new URL)
  that silently broke spell-casting in production builds
- Close a DUPL lint bypass in the SNOBOL4 spell linter
- Isolate spell verification into per-spell child processes (fixes a
  CI-hang risk and a WAForth memory leak across repeated runs)
- SHA-pin GitHub Actions, fix a silently no-op CI typecheck step
- Add .gitignore, .npmrc, LICENSE, NOTICE, CREDITS.md, security.txt
- Pin all dependency versions exactly (no ^/~)
- Remove risky COEP header, add frame-busting JS fallback
- Add vercel.json as an alternate deploy target
